# 🛍️ E-Commerce AI Assistant

An AI-powered e-commerce chatbot built using **Python, Flask, Machine Learning, Sentence Transformers, and Ollama (Qwen 2.5)**.

The chatbot can understand user intent and handle:

- 📦 Order & delivery FAQs
- 💻 Product information
- ⭐ Product recommendations
- 📝 Customer reviews

## ✨ Features

- Intent Detection using Machine Learning
- TF-IDF based product retrieval
- Semantic embeddings using Sentence Transformers
- AI-generated responses using Qwen 2.5
- Flask web application
- Interactive chatbot UI

## 🛠️ Technologies

- Python
- Flask
- Scikit-learn
- Pandas
- Sentence Transformers
- Transformers
- Ollama
- Qwen 2.5
- HTML, CSS, JavaScript
